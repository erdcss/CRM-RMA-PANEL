# Çalışkan Business

Yönetici mobil uygulaması için izole Expo altyapısıdır.

- Mevcut `mobile/` klasörü Çalışkan B2B olarak korunur.
- Bu uygulama web admin panelinden atanan `app_access=business` hesaplarını kullanacaktır.
- Operasyon ekranları ve yetkileri sonraki geliştirme komutlarıyla eklenecektir.
